One-time setup

The app never runs useradd as root directly. It logs in over SSH as a normal user and runs one small helper script through sudo. The helper only manages ordinary users (UID 1000 and above) and refuses root and system accounts.

  1. On the Ubuntu server, create the SSH user and install the helper (it is in the project at tools/server/mailbox-user): 
    sudo adduser --disabled-password --gecos "" mailboxadm
sudo install -o root -g root -m 0755 mailbox-user /usr/local/sbin/mailbox-user
echo 'mailboxadm ALL=(root) NOPASSWD: /usr/local/sbin/mailbox-user' | sudo tee /etc/sudoers.d/mailbox-user
sudo chmod 0440 /etc/sudoers.d/mailbox-user
sudo visudo -c
  2. On the machine running Docker, create a key and allow it on the server: 
    mkdir -p ssh && ssh-keygen -t ed25519 -N "" -f ssh/id_ed25519 -C mailbox-app
# copy ssh/id_ed25519.pub into /home/mailboxadm/.ssh/authorized_keys on the server
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub   # run on the server: host fingerprint
  3. In .env: 
    LINUX_USERS_ENABLED=True
LINUX_SSH_HOST=66.116.244.109      # or host.docker.internal for the Docker host itself
LINUX_SSH_USER=mailboxadm
LINUX_SSH_KEY_FILE=/app/ssh/id_ed25519
LINUX_SSH_HOST_FINGERPRINT=SHA256:...
  4. docker compose up -d, then press Test connection.

Users created here get a home folder and, with Dovecot/Postfix using system accounts, a mailbox. Choose Mail only unless they really need SSH access.
